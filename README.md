One word for make.fun's "One Word, One Username, One Reward" bounty: the entrant's own make.fun username, and nothing else.

`main.py` writes a single word to `/output/entry.txt`:

> expylar

The word is 7 characters, one word, under the 30-character cap. It is not a word chosen for funniness: the judge's first criterion is that the entry is the entrant's own genuine make.fun handle, and any entry that is not loses to any genuine handle. So the entry is the handle itself — short (7 bytes, good for the size tie-break), one word, no padding, no gloss.
